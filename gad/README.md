# EviTrace GAD Application

The Government Analyst's Department (GAD) application is part of the EviTrace university prototype. It uses fictional evidence and case records.

## Planned workflow

1. Receive and verify evidence transfers from police stations.
2. Record the receiving officer's decision and the condition of the evidence.
3. Assign an analyst and track the examination.
4. Review, sign, and issue a forensic report.

## Local development

The application will run locally with Docker Compose.
